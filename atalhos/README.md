# Atalhos

Use só estas pastas no dia a dia. O que é raro fica em `avancado`.

## servidor (PC do Domínio)
| Atalho | Para que serve |
|---|---|
| Configurar Acesso Rede.bat | Define o IP/porta e gera o pacote da interface para outros PCs |
| Liberar Acesso Rede.bat | Regra de firewall (executar como administrador) |
| Instalar Servidor Permanente.bat | Servidor sobe sozinho no logon, sem janela, e reinicia se cair |
| Ver Servidor Permanente.bat | Mostra se a tarefa do servidor está instalada |
| Remover Servidor Permanente.bat | Remove a tarefa e encerra o servidor aberto |
| Executar Dominio na Rede.bat | Modo manual (deixe a janela aberta) |

`Servidor Oculto.vbs` e `Servidor Permanente (loop).bat` são internos da tarefa permanente.

## ferramentas
| Atalho | Para que serve |
|---|---|
| Verificar Ambiente.bat | Mostra o que falta no PC (Python, Tesseract, tela) |
| Calibrar Tela Principal.bat | Calibração da tela azul (uma vez por PC/resolução) |
| Executar Presumido em Lote.bat | Lote Lucro Presumido por atalho (servidor PARADO) |
| Executar Presumido por Empresa.bat | Uma empresa por vez por atalho |
| Modo Seguro / Modo Rapido / Ver Otimizacoes | Liga/desliga as otimizações de velocidade |
| Voltar Versao Estavel.bat | Volta para a última versão marcada como estável |
| Limpar Pastas.bat | Remove capturas, caches e backups antigos (nunca configuração) |
| Gerar Pacote Instalador.bat | Refaz o projeto.zip e os arquivos do instalador a partir do origin/main |

## avancado
Testes por rotina, diagnóstico de PDF, OCR opcional (Paddle), atalho curto de saída, destino de livros, interface
gráfica antiga e motor SPED. Os servidores de teste/simulação foram removidos.

Guias de instalação: `instalador/1 - Instalar em outro PC.txt` e `instalador/2 - Ligar o servidor.txt`.
Os documentos em `docs/` são histórico e ainda citam alguns atalhos antigos.
